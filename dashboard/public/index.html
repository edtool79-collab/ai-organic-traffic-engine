הגדרת משימה ספציפית (Custom User Journey & QA Assertions)
במצב "משימה ספציפית" הדפדפן לא סתם מטייל אקראית — הוא מבצע בדיוק את הצעדים שקבעת, בודק תוצאות (Pass/Fail) ומשדר תמונת מסך חיה.
מדריך ב־10 שניות — איך מכוונים את הבוט ומסתכלים עליו עובד:
  • כבר הכנו לך הכל למטה (10 צעדים מוכנים): פשוט הסתכל על הרשימה ולחץ למעלה משמאל על הכפתור הירוק "הפעל הרצה ▶" — ייפתח דפדפן אמיתי ותוכל לראות הכול בעיניים.
  • רוצה להגיע לדף או לאזור מודעה בלי ללחוץ עליו? הוסף צעד goto (עמוד) או scroll_to (גלילה אל aside.ad-slot-box[...]).
  • רוצה ללחוץ על כפתור באתר שלך? הוסף צעד click וכתוב בשדה "בורר" את שם הכפתור (כמו #lc-clean). שכבות הפרסומת והפופ־אפים נסגרים מעצמם!
📚 מדריך עצמאי מלא — איך מגדירים לבד צעדים, לחיצות (Selectors) והתנהגות אנושית

איך בוחרים על מה ללחוץ (Selector):

  • הדרך הפשוטה (טקסט): כתוב רק את המילים שעל הכפתור/קישור (למשל קרא עוד או About). בלי # או . — המערכת מוצאת אותו לבד.
  • מזהה או מחלקה (CSS): לפי ID ← #submit-btn | לפי Class ← .read-more | לפי קישור ← a[href*="/article"].
  • העתקה ב-3 שניות מ-Chrome: קליק ימני על הכפתור באתר ← בדיקה (Inspect) ← קליק ימני בקוד ← Copy → Copy selector ← הדבקה בשדה בורר.
