📚 Complete Self-Service Reference — Step Types, Selectors & Human Behavior

How to target an element (Selector):

  • Plain Text (Easiest): Type the visible text on the button or link (e.g. Read More or About) without # or . — the runner locates it automatically.
  • CSS Selector: By ID → #submit-btn | By Class → .read-more | By Href → a[href*="/article"].
  • 3-Second Chrome Copy: Right-click the element on your page → Inspect → right-click the highlighted DOM node → Copy → Copy selector → paste into the Selector field.
