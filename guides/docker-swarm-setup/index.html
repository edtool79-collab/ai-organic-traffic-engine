Self-Hosted Docker Swarm & Local Quickstart

Clone from GitHub, configure .env.local safely, scale Playwright workers with Docker Compose, and verify everything with offline tests.

Get Source on GitHub Build config.json Get HirePulse Credits

1. Local installation (Windows & Node.js LTS)

git clone https://github.com/edtool79-collab/ai-organic-traffic-engine.git
cd ai-organic-traffic-engine
npm install
npm --prefix dashboard install
npx playwright install chromium firefox webkit
Copy-Item config.example.json config.json
Copy-Item .env.example .env.local
npm start

Open http://127.0.0.1:4310 to launch the dashboard, or execute headless runs straight from CLI with node src/crawleeRunner.js config.json.

2. Docker Compose Swarm & Lightpanda CDP

For multi-container horizontal scaling on Linux hosts, docker-compose.yml defines three profiles with loopback-bound ports and isolated mounts for data/, site-profiles/, and session-profiles/:

docker compose up -d dashboard
docker compose --profile swarm up -d --scale worker=4
docker compose --profile lightpanda up -d

Workers receive 2gb /dev/shm and a 2560M container memory limit per replica, while the optional Lightpanda container exposes CDP on 127.0.0.1:9222.

3. Offline verification suite ($0 cost)

npm test
node tests/verify-plan.js
node tests/verify-proxy-resolution.js
node tests/verify-proxyscore.js
node tests/verify-residential.js
node tests/signup-release.js
node tests/verify-engine.js chromium

Every file under config.json, .env.local, proxies.txt, reports/, and runs/ remains excluded by .gitignore so secrets never leak to public repositories.
