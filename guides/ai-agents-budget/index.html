How to Run AI Browser Agents on a Fixed Budget

Control token costs in Playwright automation with clef:27b /v1/systemone routing, workerPct splits, Playbook Caching, and HirePulse Cloud Credits.

Get Source on GitHub Build config.json Get HirePulse Credits

1. Separate commander and decision worker models

Assign glm-5.3-flash or deepseek-v4.1-flash to commanderModel for natural-language planning and run summaries, and assign clef:27b to workerModel / recoveryModel to route DOM choices via /v1/systemone with zero prose output tokens.

2. Tune workerPct per run

  • 20% (Light): Deterministic recorded steps handle normal pages; AI triggers only on selector drift or form guard events.
  • 50% (Balanced): Half of visits explore dynamically; half replay fast scripted flows.
  • 100% (Full Autonomous): Every session evaluates layout, tools, and guides interactively.

3. Reuse Playbook Cache or connect HirePulse Cloud Credits

Set ai.provider = "hirepulse" with a key from gethirepulse.xyz/credits to run Commander, step decisions, and public funnel audits from one prepaid balance with automatic local fallback if credits run out.
